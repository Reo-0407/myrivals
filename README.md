# MyRivals

웹에서 하는 1인칭 슈팅(FPS) 미니게임. 친구/팀원은 전부 **AI 봇**이고, PC와 모바일에서 모두 할 수 있어요.

- 접속하면 **닉네임 입력 → 로비 → 매치 시작**. 로그인/관리자 화면 없음
- 모드 1v1 ~ 4v4, 5선승, AI 난이도 5단계(**입문**/쉬움/보통/어려움/지옥). 처음엔 입문을 추천
- **🎯 사격장**: 로비에서 바로 입장. 고정/움직이는 과녁, 거리 표시, 명중률·헤드샷 통계, 일시정지에서 무기 자유 교체
- **폰 조작 보조**: 에임 보조(적 쪽으로 살짝 끌어줌), 자동 발사, 발사 버튼을 누른 채 드래그해서 조준, 레이더, 맞은 방향 표시
- **맵 4종**: 창고 단지(2층 건물/컨테이너/고가 통로), 사막 마을(광장/흙벽돌 집/골목/지붕), 항구 부두(컨테이너 골목/가운데 관리동/크레인), 설원 기지(얼어붙은 호수/통나무집/눈 방벽). 로비에서 선택
- **🛒 상점**: 경기에서 번 코인으로 무기 스킨 8종(위장/핑크/아이스/루비/네온/황금/무지개)과 조준점 색을 사서 장착. 3D 미리보기 제공. 코인은 이기거나 적을 처치할수록, 어려운 난이도일수록 많이 줘요 (코인은 이 기기에만 저장)
- **관전 모드**: 죽으면 살아 있는 아군 시점으로 보고, 탭/클릭으로 다음 아군으로 넘어가요
- 무기 15종 (주무기 6 / 보조 3(권총·리볼버·활) / 근접 2 / 유틸리티 4), 무기마다 다른 재장전 시간
- 리더보드 (승/킬/데스)

## 실행
```bash
npm install
npm start
```
`http://localhost:3000` 접속. 같은 와이파이의 폰은 PC의 로컬 IP(`ipconfig`)로 접속.

## 공개 링크로 배포 (Render)
1. [Render](https://dashboard.render.com) → **New → Blueprint** → 이 저장소 선택 (`render.yaml`이 설정을 채워줌)
   - 또는 **New → Web Service**: Build `npm install`, Start `npm start`
2. 배포가 끝나면 `https://○○○.onrender.com` 이 게임 주소. 이후 `git push` 하면 자동 재배포.

무료 플랜은 한동안 접속이 없으면 잠들어서 첫 접속이 느리고, **재시작/재배포 때 리더보드 기록이 지워질 수 있어요.**

## 조작
| | PC | 모바일(가로 화면) |
|---|---|---|
| 이동 | WASD | 왼쪽 화면 조이스틱 (끝까지 밀면 달리기) |
| 시점 | 마우스 | 오른쪽 화면 드래그 |
| 발사 / 조준 | 좌클릭 / 우클릭 | 발사 버튼(누른 채 드래그하면 시점도 회전) · 왼쪽에도 발사 버튼 / 조준 버튼(토글) |
| 장전 / 점프 | R / Space | 장전 / 점프 버튼 |
| 앉기 | C 누르는 동안 | 앉기 버튼(토글) — 눈높이가 낮아져 낮은 상자 뒤에 숨을 수 있고 더 정확해짐 |
| 무기 교체 | 1·2·3·4, 휠, Q | 아래쪽 무기 버튼 |
| 점수판 | Tab | 위쪽 점수 상자 탭 |

## 구조
```
server.js          정적 파일 + 닉네임/리더보드 API (Express)
rival-server.js    API 구현 (data/rival.json 에 저장)
public/
  index.html       닉네임 / 로비 / 게임 화면
  main.js          로비, HUD, 매치(라운드), 입력(PC/모바일)
  weapons.js       무기 수치표 + 발사/재장전 상태 머신 (밸런스는 여기 숫자만 고치면 됨)
  maps.js          맵 공용 도구 + 창고 단지 맵
  map-village.js   사막 마을 맵 (RivalMap.register 로 등록)
  map-harbor.js    항구 부두 맵
  map-snow.js      설원 기지 맵
  models.js        3D 모델 (무기/캐릭터, 스킨 색 적용)
  shop.js          상점(코인 지갑, 스킨/조준점 목록, 3D 미리보기)
  bots.js          봇 AI (A* 길찾기, 역할별 동선, 플레이어 학습, 빗나감 연출, 난이도)
  physics.js       충돌/총알 계산
  audio.js         효과음 (코드로 합성, 음원 파일 없음)
```

테스트용 주소 옵션: `?debug`(콘솔에서 `__rival` 접근, `__rival.step(n, dt)`로 게임 시간 빨리 감기), `?rounds=1`(1선승).

## 맵 추가하기
`public/map-village.js`를 복사해서 새 파일을 만들고 `RivalMap.register('아이디', { name, build(c) { ... return { boxes, spawns, name, sky }; } })`를 호출한 뒤 `index.html`에 script 태그를 추가하면 로비 맵 목록에 자동으로 나와요. 맵은 64x64m 안(담장 ±32), 스폰은 팀당 7곳이에요. 봇 길찾기 격자는 맵을 불러올 때 자동으로 만들어져요(문 폭은 2.4m 이상, 스폰은 담/벽에서 1m 이상 띄우세요).

## 난이도 조절
`public/bots.js` 맨 위 `DIFFS` 표의 숫자만 고치면 돼요(반응 시간 `react`, 조준 오차 `aim`, 데미지 배율 `dmg` 등). 에임 보조 강도는 `public/main.js`의 `findAssistTarget`.

## 알려진 한계
- AI는 보통 이상 난이도에서 내 습관(자주 있는 곳/싸우는 거리)을 이 브라우저에 기억해서 점점 잘 싸워요. 설정 → '기억 지우기'로 초기화할 수 있어요. 입문/쉬움은 학습하지 않아요.
- **🤝 친선전투(온라인)**: 로비에서 `친선전투`를 누르면 지금 접속 중인 사람 목록이 보이고, 방을 만들어 초대하거나 방 코드(4글자)로 들어갈 수 있어요. 방 안에서 팀(A/B) 칸을 눌러 팀을 바꾸고, 방장은 모드(라운드제 / 팀 데스매치)·맵·팀 인원(1~4)·몇 선승(데스매치는 목표 킬 수)·AI 켜기/끄기·AI 난이도·무기 랜덤을 정해요. 팀 데스매치는 죽어도 3초 뒤에 다시 나오고 5분 안에 먼저 목표 킬을 채우는 팀이 이겨요. AI를 켜면 빈 자리를 AI가 채우고, 끄면 사람끼리만 싸워요. 경기 진행과 AI는 방장의 기기가 맡아요(기록/코인은 없어요).
- 로비에서 **몇 선승**(1~10)을 고를 수 있고, **무기 랜덤**을 켜면 라운드마다 주무기/보조/근접/유틸리티가 무작위로 나와요. 선승 수가 적을수록 받는 코인이 줄어요.
- 봇은 나를 한 방에 죽이지 못해요(총알 한 발 최대 60, 샷건 한 번 최대 55). 저격총/샷건도 최소 2번은 맞아야 쓰러져요.
- 봇도 가끔 빗나가요(조준 흔들림, 처음 몇 발 어긋남, 맞으면 움찔). 난이도가 높을수록 덜 빗나가요.
- 봇도 계단을 올라 2층/지붕을 써요. 보통 이상 난이도의 봇은 라운드마다 한 번 유틸리티(수류탄/섬광탄/연막탄)를 써요.
- 기록은 브라우저가 보내는 값을 믿는 구조라 조작할 수 있어요(15초 간격 제한, 같은 주소에서 계정 대량 생성 제한만 있음). 코인/스킨도 이 기기 브라우저에만 저장돼서 조작할 수 있어요(꾸미기 전용이라 상관없어요).
- 앉기, 활, 상점/스킨은 아직 없어요.
- 아이폰 사파리는 전체화면을 지원하지 않아요. 공유 버튼 → **홈 화면에 추가**로 열면 주소창 없이 전체화면으로 쓸 수 있어요.
